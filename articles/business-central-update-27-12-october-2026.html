Business Central Update 27.12 Released: What Developers Should Check

October 3, 2026 · Business Central 2025 release wave 2 · On-premises

Microsoft has published Update 27.12 for Dynamics 365 Business Central 2025 release wave 2. The update is listed for October 2026 and is the latest cumulative update currently shown in Microsoft's release list for the 27.x on-premises line.

Build details
Application Build: 27.12.55425
Platform Build: 27.0.55363
Knowledge Base: 5130860

For teams still running Business Central 27.x on-premises, this is the update worth checking before planning another maintenance window. Microsoft describes cumulative updates as containing the hotfixes and regulatory features released in previous cumulative updates as well. citeturn1search0

What stands out for developers?

The update is not a new major version. That distinction matters. An update such as 27.12 is mainly a cumulative maintenance release, so the practical work for a developer is usually around compatibility, regression testing and making sure custom extensions and integrations continue to behave correctly.

Microsoft's published 27.x update history includes fixes across platform, application, integration and security-related areas. Earlier 27.x updates, for example, included changes around web request security, authentication URL handling, task execution and Shopify API compatibility. citeturn1search1

If you are running Business Central 27.x on-premises

Before applying the update to a production environment, I would check these items first:

  • Record the current application and platform build.
  • Take a tested database backup and confirm the recovery procedure.
  • Check installed extensions and their compatibility with the target build.
  • Test custom APIs, HttpClient integrations and authentication flows.
  • Run the important posting, report and document scenarios used by the business.
  • Test Job Queue and scheduled background processes.
  • Check web client, service tier and authentication configuration after the upgrade.
  • Review third-party extensions before the production maintenance window.
One important point: Microsoft recommends checking compatibility with customizations and third-party products before installing updates. That matters especially for on-premises environments where the customer controls the application stack. citeturn1search4

What about developers working on AL extensions?

Do not assume that a cumulative update means “nothing to test.” A platform hotfix can affect behavior around APIs, tasks, permissions, web requests, reports or client functionality even when your own AL code has not changed.

A sensible approach is to publish your extension to a test environment first, compile it against the target symbols, run automated tests if available, and then perform a short business-process regression test.

One more thing: version 28 and the 2026 wave

Microsoft's current update pages also show the separate Business Central 2026 release wave 1 line, with Update 28.5 listed for September 2026. At the same time, version 29.0 is shown as a preview for the 2026 release wave 2. citeturn1search2turn0search1

So organizations should distinguish between maintaining an existing 27.x environment and planning a major-version upgrade. Those are different projects with different testing and compatibility considerations.

AI and Business Central are moving in parallel

Another current direction is Microsoft's expansion of agent capabilities in Business Central. Microsoft's roadmap lists an agent design experience for October 2026 general availability, while the enhanced MCP work is aimed at connecting AI agents to Business Central data and APIs with stronger validation, telemetry and authentication support. citeturn0search3turn0search7

For AL developers, that makes API design, permissions, authentication, telemetry and clean business logic increasingly relevant even when the immediate task is a normal extension.

Bottom line for a 27.x developer

If your environment is on Business Central 27.x, Update 27.12 is worth putting on the maintenance checklist. The important part is not simply installing the latest build; it is verifying the applications, extensions and integrations that your environment actually depends on.
